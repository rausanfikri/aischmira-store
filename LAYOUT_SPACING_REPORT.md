## 2. Standardized Layout & Spacing Scale

### Horizontal Padding Scale
- **Desktop (>=1024px)**: `80px` (`lg:px-[80px]`)
- **Laptop (768px – 1023px)**: `64px` (`md:px-[64px]`)
- **Tablet (640px – 767px)**: `40px` (`sm:px-[40px]`)
- **Mobile (<640px)**: `24px` (`px-6`)

### Section Vertical Rhythm
- **Flagship Editorial Sections**: `160px` top/bottom padding (`lg:py-40`)
- **Standard Page Sections**: `120px` top/bottom padding (`md:py-30`)
- **Compact Sections**: `96px` top/bottom padding (`py-24`)
