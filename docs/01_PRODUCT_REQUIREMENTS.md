# Product Requirements

## Target User

Wanita usia 20–40 tahun yang menyukai fashion premium, elegan, dan timeless.

---

## User Goals

- Menjelajahi koleksi
- Melihat detail produk
- Memilih warna dan ukuran
- Menambahkan ke keranjang
- Mengenal cerita brand

---

## Functional Requirements

### Homepage

- Hero Banner
- Featured Collection
- New Arrival
- Brand Story
- Instagram Preview
- Newsletter
- Footer

---

### Collection

- Filter
- Search
- Sort

---

### Product

- Gallery
- Variant
- Size
- Price
- Description

---

## Non Functional

- Mobile First
- Fast Loading
- SEO Friendly
- Accessible
- Reusable Components
