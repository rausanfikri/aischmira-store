# AISCHMIRA.STORE — Spacing Review
**Sprint:** 2C — Luxury Layout System + Collection Experience
**Date:** July 28, 2026

---

## 1. Vertical Rhythm Scale

Vertical spacing between major sections was standardized into 3 breathing tiers:

- **Standard Section Gap (`py-24`)**: `96px` (Mobile & tablet default)
- **Sub-Hero Section Gap (`py-30`)**: `120px` (Laptop section spacing)
- **Major Editorial Gap (`py-40`)**: `160px` (Desktop flagship section spacing)

This generous whitespace ensures the website feels calm, unhurried, and luxury-first.

---

## 2. Standardized Grid Gap System

- **Desktop Gap**: `32px` (`gap-8` / `lg:gap-8`)
- **Tablet Gap**: `24px` (`gap-6` / `sm:gap-6`)
- **Mobile Gap**: `16px` (`gap-4`)

Verified across product grids, collection cards, Instagram previews, brand values, and footer navigation columns.
